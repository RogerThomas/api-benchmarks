## Key findings
- **jero is the #1 Python framework on all four tests** (2.5× fastapi on JSON, 3.3× on JWT),
  running at 97–101% CPU = at its true single-core ceiling. Python order is stable everywhere:
  jero → blacksheep → litestar → fastapi → flask.
- gin/elysia lead overall (native runtimes, no GIL) — expected. elysia narrowly tops raw JSON
  and, after the Bun-fetch fix, is also the fastest proxy (47k vs gin 33k); gin is the
  all-rounder.
- 100% success on every framework/test. (elysia/test3 initially failed in this run — since
  root-caused, fixed, and re-verified at 100%; see below.)

## RESOLVED (same day) — elysia/test3 (proxy) failure root-caused & fixed
Root cause: Bun `fetch` keeps a 64-conn keep-alive pool per host but does not queue
overflow — >64 concurrent fetches open one-shot connections that flood TIME_WAIT and
exhaust the container's ~28k ephemeral ports in ~4s. Fix: `BUN_CONFIG_MAX_HTTP_REQUESTS=64`
(compose.yml) — same 64 outbound budget as every other framework. **Verified re-run through
the full harness at the identical failing settings (30s, VUS=128, best-of-3):
46.8k req/s @ 100% success, mean 2.66ms, p99 9.25ms** (was 5.3k @ 85.7%). That re-run is
merged into the canonical report JSON and the tables below (the standalone re-run report
is `results/report-20260715T134809.json`).

### Original issue record (for the paper trail)
- 3s / VUS=128  → 16k, **100%** success
- 30s / VUS=100 → 9.2k, **93.3%** success
- 30s / VUS=128 → 5.3k, **85.7%** success (p99 106ms)  ← the failing run in the tables below
- Duration-and-load driven; short runs hid it. gin's proxy was 100% throughout (its
  Transport queues excess over the keep-alive pool instead of churning connections).

## Caveats
- Measured on Docker Desktop's Linux VM (Apple Silicon). vCPU→physical pinning is near-exact
  here, exact on bare metal.
- gin/elysia are CPU-bound by ~128 VUs (ceilings ≈ gin 88k, elysia 92k on JSON). Higher VUs
  does not raise throughput — confirmed by the 128/256/512 sweep.
- Pending: bare-metal x86 Linux run (exact pinning + Robyn rejoins the lineup).

# jero-benchmarks — final run v2, 2026-07-16 (pyreqwest era)

**Config:** docker · VUS=128 · 30s/test · best-of-3 · 1 dedicated CPU core per framework
(cpuset affinity) · granian+uvloop for ASGI · Robyn excluded (no aarch64 wheel).
**Change vs v1:** every Python framework's outbound HTTP client migrated from
niquests (pure Python) to **pyreqwest** (Rust reqwest); Flask uses its SyncClient.
Raw JSON: `results/report-20260716T085633.json` (jero/test3 re-run after the
default-headers refactor merged in; standalone re-runs: `report-20260716T105643.json`, `report-20260716T110554.json`) · v1 (niquests era): `FINAL-2026-07-15-vus128.md`

## v1 → v2 delta (the client migration, test 3)

| framework | v1 (niquests) | v2 (pyreqwest) | gain |
| --- | --- | --- | --- |
| jero | 3.4k / p99 71ms | **30.5k / p99 10ms** | **9.0×** |
| blacksheep | 2.9k | 25.1k | 8.7× |
| litestar | 2.9k | 18.5k | 6.4× |
| fastapi | 2.7k | 14.7k | 5.4× |
| flask (sync) | 2.4k | 6.0k | 2.5× |

Tests 1/2/4 moved only within run-to-run variance — the client isn't on those paths.

## Key findings
- **jero is the #1 Python framework on all four tests**, at ~100% CPU (true single-core
  ceiling). Python order is identical everywhere: jero → blacksheep → litestar → fastapi
  → flask.
- **Test 3 now measures frameworks, not the HTTP client.** Under niquests every Python
  framework was pinned at ~3k (client-bound); with the same Rust client for all, the
  familiar framework spread re-emerged (30k → 6k).
- **jero proxies within ~10% of gin** (30.5k vs 33.8k) with an equal p99 (~10ms) — a Python
  framework at Go-level proxy throughput.
- elysia (post Bun-fetch fix) is the fastest proxy overall (47.6k); gin remains the
  all-rounder and tops tests 1/2/4.
- 100% success on every framework/test; zero port errors.

## Caveats
- Docker Desktop Linux VM (Apple Silicon); pinning near-exact here, exact on bare metal.
- gin/elysia retain CPU headroom on test 1 (87%/72%) — VU-limited there; Python
  frameworks are at their genuine ceilings.
- Pending: bare-metal x86 Linux run (exact pinning + Robyn rejoins).
